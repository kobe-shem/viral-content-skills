# Viral content

Turn a real audience tension into a watchable, useful video or persuasive ad. Keep the business objective, argument, creative format, and editing style separate. A claymation execution can carry a direct-response argument; a talking head can entertain, educate, or sell.

## Start with the requested work

Use supplied context to identify the brand, audience/situation, organic or paid objective, requested scope, format, and available evidence. Read the project's brand/offer facts and relevant prior research when present. Ask only for missing information that changes the work. A short rewrite should not require a research project or an intake form.

For persistent project context, check `.viral/brand-context.md` in the current project when present, or the profile explicitly supplied by the user. A profile index may point to separate brand/speaker files; load only the selected brand. Keep this optional convention private to the project. Never assume that a profile for one client governs another.

Read [craft.md](references/craft.md) and the applicable [mode](references/modes.md). Then load the stage needed:

Enter at any stage. Preserve an approved idea, script, hook, claim, or format unless the request changes it or an identified issue needs resolution. When rewriting only an ad's body, keep its boundary and do not append a new hook/CTA automatically.

For a larger research or production operation, use [orchestration](references/orchestration.md) to delegate collection and retain strong creative judgment. Use [creator decisions](references/creator-decisions.md) when source-specific teaching changes the work.

For concrete reference mechanisms, consult the [paid creative cases](references/paid-cases.md) or [organic comparisons](references/organic-cases.md). Read the relevant case rather than loading the entire research archive for every script.

## Shared decisions

- **Hook promise and payoff:** name the specific question, expectation, or tension the opening creates. Deliver an early useful step and a satisfying resolution; do not withhold all value until the end.
- **Relevant attention:** for paid work, the opening should attract likely buyers for the actual offer. Spectacle must connect to the argument. Organic reach can be broader while retaining a clear intended audience.
- **Three hook channels:** spoken line, visible text, and pictured action should make one coherent promise. They can complement each other; verbatim repetition is optional. A caption is not evidence of what appeared on screen.
- **Progression:** each beat changes what the viewer knows, expects, feels, or can do. Rephrasing the same problem three times is not development.
- **Truth and voice:** use the selected brand's facts and speaker's actual experience. An illustrative scene is not proof. Keep personal voice preferences in the project; never require a particular founder's story or language from every user.
- **Conditional doctrine:** creator teachings, observed patterns, editorial preferences, and measured campaign results are different evidence. Consult [sources.md](references/sources.md) for provenance and exceptions. Views, longevity, and provider scores do not establish profitability or causation.
- **Concrete execution:** visual direction names the action, framing, graphic, timing, and narrative purpose. “Add a pattern interrupt” is unfinished direction.

## Scale the deliverable

For a rewrite, give the usable copy first and explain only consequential choices. For concept development, give distinct ideas and recommend the strongest with a reason. For production, provide the script plus synchronized visual/action notes and a handoff to editing. Store sources and detailed rationale in the project, not inside spoken copy.

Use existing research and authorized account data before acquiring more. Live research is optional when the supplied brief is sufficient. Tools and accounts belong to the current environment; credentials and client material never belong inside this skill package.

Ball Script is an optional deadpan/comedic style, not a synonym for viral doctrine. Use it when that style is requested or chosen. Existing `video-edit` and `video-style-study` handle rendering and measured style packs; see [handoffs.md](references/handoffs.md). If absent, provide a complete editor-neutral production brief.
