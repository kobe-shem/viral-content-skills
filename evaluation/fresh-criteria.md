# Fresh execution checks

These briefs are constructed for evaluation and contain no customer claims. Freeze the skill snapshot and generated outputs before the reviewer sees this checklist. The writer can see only the briefs and relevant skills.

| Case | Meaningful checks |
|---|---|
| Paid UGC | Full exact speech, plausible counter action, useful product demonstration, no fabricated first-person testimonial or unsupported test result |
| Claymation | Clearly illustrative physical state change, app only flags low stock, human still orders, synchronized VO/picture/graphics and believable production plan |
| Skit | Distinct wants, causal interaction and reactions, stable roles/eye lines, product resolves the room conflict without unsupported integrations |
| Jumbotron | Readable display, relevant opening/reveal, feasible 15-second sequence, staged scene stays distinct from actual event placement/endorsement |
| Organic education | Actionable worked example in-video, early reward, final promise fulfilled, no automatic commercial CTA |
| Aware paid | Product visible immediately, direct folding answer, no mandatory delayed pitch or unnecessary problem lecture |
| Body-only | No fresh hook/CTA/style preamble, natural problem→consequence→product progression, exact facts preserved |
| Rejected topic | Three developed workshop concepts, rejected family topic stays retired, no false claim that missing founder stories prevents all ideation |

For every case, assess speech, idea quality, useful visual execution and timing realism. Word-count estimates are not recorded runtimes. A checklist pass shows instruction-following and basic craft usability; it does not establish that the creative is distinctive, preferred by the owner or commercially successful.
