# Optional editing-skill bridge

The portable suite does not bundle a renderer or replace another skill's media ingest. When integrating with an installed editing skill, its router can use this instruction:

> When scripting or ideation is needed, use `viral-content`, `viral-script` and `viral-direct` for audience/offer reasoning, words and visual planning. Preserve the approved script. Treat the production brief as planning input before ingesting and timing actual media. Ball Script is a separate optional comedic style. Use the existing generation skills for missing media and the editing skill's own measured timeline/render/review workflow.

Use this only where those skills are installed. A source project's editing instructions may be managed in another repository; preserve that project's workflow and record any local integration patch so a later update can retain it.

The handoff is a script plus a concrete beat/asset plan. Once media exists, the editor establishes actual durations, speech boundaries, cuts and caption timing. A planning JSON file must not be mistaken for a final playable timeline.
